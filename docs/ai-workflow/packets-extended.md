# Extended Engineering Packets

Load only the record needed. Use the common evidence fields from `packets.md`.

## Context

Record task understanding, relevant files/state owners, inspected behavior,
risks, existing tests, unresolved decisions, and the minimum source the next
host should read.

## Effort upgrade

Record only the material goal, decisions, state, failures, risks, and evidence
the replacement thread needs to continue without repeating verified work. Do
not turn continuity context into a prescribed solution.

## Parallel lease

Record the worker, task, base revision, exclusive write/state scope, prohibited
collisions, integration owner, stop condition, return evidence, and final
artifact disposition.

## Routing evaluation

Record the task class, candidate host/model/instructions, quality and
verification outcome, latency/token/cost/intervention, decision, and
re-evaluation trigger. Retain only data allowed by project privacy policy.
