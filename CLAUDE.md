# Claude-specific routing

The collaboration default is in `AGENTS.md`; this file adds only what is
Claude-specific.

Check the channel the environment provides before reporting Codex unavailable.

When delegating or coordinating across hosts, use the minimum sufficient
collaboration contract and independent-judgment boundary in
`docs/ai-workflow/capability-routing.md`, and choose the smallest adequate
capability. Do not turn a suggestion into a decided fact.

Read `docs/ai-workflow/capability-routing.md` for role changes, delegation, or
parallel work; `git-execution.md` for Git ownership; and `packets.md` only
when a formal handoff, review, or acceptance claim is needed.

Where framing, architecture, or acceptance is still uncertain, open the peer
challenge round in `capability-routing.md` before settling acceptance criteria
with the Owner, and carry what it changed into the brief. Send the question and
the evidence, not the conclusion you want back.

To run work through an execution network, create or brief the Lead with
`agents/assignment-template.md`; the Lead loads
`docs/ai-workflow/execution-network.md`. A Codex session that is not given the
Lead assignment implements the task directly under the ordinary defaults,
which is also a reasonable outcome.
